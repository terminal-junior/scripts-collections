# Scripts Collections

Repositório dedicado à coleção de scripts utilitários para automação, manutenção, diagnóstico e produtividade em sistemas Unix-like (Linux, BSD, macOS) e ambientes diversos.

O objetivo deste repositório é centralizar scripts simples, reutilizáveis e bem documentados, facilitando o uso no dia a dia e o aprendizado.

---


## ▶️ Como Usar

Clone o repositório:

```bash
git clone https://github.com/terminal-junior/scripts-collections.git
```

Navegue até o diretório do script desejado:

```bash
cd scripts-collections/bash/utils/
```

Dê permissão de execução (se necessário):

```bash
chmod +x script.sh
```

Execute:

```bash
./script.sh
```
